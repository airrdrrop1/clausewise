ClauseWise

Know what you sign. Paste a contract and get a plain-language brief: structured facts, obligations and deadlines, and red flags — every warning quotes the exact clause it came from, and each quote is machine-checked against your text before it is shown as verified.

OFFLINE DEMO MODE — this public page runs the same clearly-labelled demo as the repository's mock mode (no API key in the browser, by design). The brief below is the built-in sample result; load the sample contract to watch every quote verify end-to-end. Paste different text and the sample quotes will be flagged as unverified — that checking layer is real code running in your browser (whitespace/case-normalized substring match, the same rule as analyze.py:verify_quotes).
